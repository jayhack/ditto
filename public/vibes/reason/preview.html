02.1  ·  UX · Install guide EST. READ: 3 MIN · 4 STEPS

Get Reasonix on your machine in four steps.

Reasonix is a single binary you point at any working directory. On first run it reads ~/.reasonix/config.toml, pulls your DeepSeek key, and opens an append-only session.

01
Install the binary
brew install reasonix · 7.2 MB
brew install 7.2 MB
02
Add your DeepSeek key
reasonix login · stored in keychain
reasonix login ~/.config
03
Open a session in your repo
cd ~/app && reasonix code
reasonix code v0.51.0
04
Leave it running
cache holds 90%+ · cost collapses to ~1/5
— ongoing — ∞
Read the install docs → npm registry
